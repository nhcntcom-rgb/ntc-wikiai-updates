# ntc-wikiai-updates

Kênh thông báo bản mới cho **WikiAI** (Công ty TNHH NTCOM).

Tệp `latest.json` ở nhánh `main` được pipeline phát hành tự động cập nhật mỗi lần ra bản mới.
Ứng dụng WikiAI chỉ **đọc** tệp này để hiển thị thông báo "có bản mới" — không tải hay chạy gì từ đây.

Địa chỉ phục vụ qua GitHub Pages:
https://nhcntcom-rgb.github.io/ntc-wikiai-updates/latest.json
